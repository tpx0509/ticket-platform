# 架构决策记录

不记录"用了 TypeScript"这种不需要论证的决定。

## 新增 ADR 的规则

1. 编号递增，文件名 `NNNN-短横线描述.md`。
2. 必须包含「备选方案」一节，且至少两个。只列一个方案等于没做选择。
3. 必须包含「后果」一节，写清这个决定带来的限制。只说好处的是宣传，不是决策记录。
4. 已被推翻的 ADR 不删除，状态改为「已废弃」并注明被哪条取代。历史是资产。
